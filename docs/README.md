## Product Positioning

`repo-meter` is not just a one-time line counter.
It is a working-session tool for:

- local repo drift awareness (`clean` vs `dirty`)
- tracked vs untracked line composition
- monolith-friendly folder-level scanning
- multi-repo monitoring in one terminal
- baseline snapshots over time

Use `scc` for low-level language counting.
Use `repo-meter` for live repo workflow visibility.
